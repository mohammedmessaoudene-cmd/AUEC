# A2A extension note - non-normative draft

AUEC can be transported as an A2A message or task artifact without making A2A itself the execution authority. A generic A2A message must not require the AUEC extension. The extension becomes required only when an AUEC manifest is present.

Formal A2A conformance is not claimed. The EB-2026-08-02 checkpoint preserves upstream failures and awaits resolution of the public TCK issues before any submission is represented as official.
