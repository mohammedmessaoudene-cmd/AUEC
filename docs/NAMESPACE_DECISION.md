# Extension namespace decision

The reference code currently uses experimental identifiers such as `org.aiew.auec` and an `aiew.example` URI. They are placeholders and are not proof of namespace ownership.

Before a formal MCP or A2A extension submission:

1. select a domain or namespace controlled by the submitter;
2. replace all experimental identifiers consistently;
3. publish the extension specification at a durable HTTPS location;
4. add migration and collision rules;
5. rerun conformance and public vectors.

A possible pattern is a reverse-DNS identifier based on a domain or verified project namespace controlled by the submitter. No specific identifier is assigned by this release.
