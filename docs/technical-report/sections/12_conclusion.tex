\section{Conclusion}
\label{sec:conclusion}

\AUEC defines a provider-neutral contract layer for hybrid AI execution. A remote planner proposes work, and a host-controlled user agent derives the effective contract. The manifest joins operations, data classifications, epistemic status, representation, placement, effects, budgets, and exports. Its deterministic \Uzero profile provides a small interoperable base; canonical hash-linked receipts make changes to a complete execution history detectable under explicit assumptions.

Historical unchanged-runner records support the exact tested MCP profiles, and four transport controls demonstrate sensitivity of selected mechanisms. Three additional controls now target the contract core: host-operation intersection, U0 epistemic admission, and a pure authorization predicate. Each prohibited case becomes possible under one exact mutation, turns its focused safety test red, and returns to the safe result after restoration. Finite checks cover 345 declared cases without a counterexample. Incomplete A2A results remain in the record.

These results directly exercise the U0 specialization of policy intersection and epistemic exclusion. The pure predicate also exercises fact status, independent validation, host effect admission, and action-bound consent as a decision. It performs no external effect, so the report does not claim a production consequential-action profile or sandbox.

The decisive next evidence must come from outside the originating implementation: independently developed runtimes, unchanged upstream A2A results after the relevant TCK questions are resolved, independently signed builds, external security review, and provider-authorized workload trials. The contract will be useful only if independent hosts enforce the same narrow semantics and reject the same unsafe proposals.
