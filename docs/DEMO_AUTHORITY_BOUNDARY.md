# Authority-boundary demonstration

`make demo-authority-boundary` provides a reviewer-runnable demonstration of
three bounded AUEC U0 guards. It is an executable negative control, not a
production action sandbox or a general MCP security claim.

## What it demonstrates

1. **Host-policy intersection.** A manifest requests `hash.sha256` after the
   host removes that operation from its allowlist. The safe runtime returns
   `E_OPERATION`. Removing only the host-allowlist check in a disposable copy
   permits execution and turns the safety oracle red.
2. **Epistemic admission.** A U0 node declares a `claim` result. The safe
   runtime returns `E_EPISTEMIC`. Widening only the admission set in a
   disposable copy permits the claim and turns the oracle red.
3. **Pure authorization predicate.** An exact action digest, independent
   validation, admitted effect and digest-bound consent authorize a `fact`.
   A `claim` is denied. Treating `claim` as `fact` in a disposable copy turns
   the oracle red.

Each changed guard is restored before the temporary directory is removed. The
restored observation must match the baseline.

## Safety properties

- deterministic U0 inputs only;
- no network access or credentials;
- no filesystem, process, device or model capability exposed to the manifest;
- no external or consequential action;
- no shell command or path supplied by an AI or other untrusted input;
- fixed subprocess arguments under repository control;
- mutations confined to an automatically removed temporary copy;
- output contains policy and observation digests, but no private local paths.

## Run

```bash
make demo-authority-boundary
```

The compact table labels a mutant as `RED_EXPECTED` only when the exact
prohibited behavior becomes observable. A successful overall verdict therefore
requires green baseline, expected red mutant, and green restoration for all
three controls.

For machine-readable output:

```bash
PYTHONPATH=reference-runtime python scripts/demo_authority_boundary.py --json
```

The committed `evidence/authority-boundary-demo.json` is generated by the same
script. The Make target compares it byte-semantically with the live execution.

## Evidence boundary

The demonstration directly supports only the tested U0 policy intersection,
U0 claim exclusion, and pure decision predicate. It performs no MCP protocol
change, production effect execution, sandboxing, external security review or
formal proof.
