# Proposed public disclosure scope

## Proposed public set after approval

- AUEC specification and architecture documentation;
- separable schemas, vectors and interface materials;
- AGPL reference runtime with exact corresponding-source metadata;
- bounded evidence summaries and hashes;
- SBOM, provenance statement and release checks;
- technical report only if the journal-policy gate permits it.

## Private or held

- raw ChatGPT/Codex conversations;
- personal account details and credentials;
- unsigned legal and institutional records;
- exact author-identifying journal manuscript until policy confirmation;
- anonymous submission package and reviewer-facing material;
- any file with unresolved third-party or collaborator rights.
