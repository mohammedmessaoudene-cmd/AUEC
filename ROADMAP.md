# Roadmap

## Current milestone - public pre-standard release

- source repository and documentation;
- technical report and DOI-ready metadata;
- sealed EB-2026-08-02 evidence as a release asset;
- draft MCP extension proposal;
- public issue tracker and governance.

## Next milestone - independent interoperability

- independent implementation in Rust, Java or another language;
- hidden-vector scoring after implementation freeze;
- independent builder and signed provenance;
- Linux VM/bare-metal and macOS execution;
- cross-organization receipt verification.

## Later milestone - security and pilot evidence

- external red-team and retest;
- production-oriented authentication and isolation profile;
- authorized provider pilot;
- paired measures of quality, tokens, latency, energy, cost and privacy;
- formalized conformance suite.

## Future milestone - standards engagement

- controlled extension namespace;
- MCP SEP submission and sponsor/reviewer engagement;
- A2A extension note after upstream TCK issues are resolved;
- optional IETF Internet-Draft for transport-neutral semantics;
- neutral governance transition.
